# PUBLIC REVIEW BRANCH ONLY

This is the privacy-safe review build.

Safeguards:
- Player cards display first name + last initial.
- Real GameChanger URL is removed.
- GameChanger controls are visible but dead.
- Real GameChanger QR is not included.
- The QR shown is deliberately nonfunctional.
- Live GameChanger widget and widget ID are removed.

UPLOAD SAFELY:
1. Open your GitHub repository.
2. Branch selector -> create/select `public-review` FROM `main`.
3. STOP and confirm the branch selector says `public-review`.
4. Upload/replace these files there.
5. Commit directly to `public-review`.
6. Do NOT merge this branch into `main`.

Your live site is not changed by uploading this package to `public-review`.
